# Python Coding Tasks

A collection of 15 Python programming tasks organized into 4 sections:

1. **Basics**: FizzBuzz, Leap Year, Identity vs Equality, Bitwise Swap
2. **Control Flow & Loops** : Prime Finder, Loop Breaker, Nested Conditionals, Reverse Integer
3. **Data Structures**: Runner-Up Score, Duplicate Removal, List Intersection, Tuple Immutability
4. **Dictionaries & Comprehensions**: Character Frequency, List Comprehension, Dictionary Comprehension
